# Gate F 生产发布门禁

当前结论：`NOT PRODUCTION CANDIDATE`。

## 必须全部满足

- [ ] 目标 Git commit 的 CI 全绿，且镜像由同一 commit 构建并使用 digest。
- [ ] 无泄漏密钥、公开指标、dev auth、通配 CORS 或公网容器直绑。
- [ ] Python 与前端生产依赖审计无已知高危漏洞；开发工具链例外有具名 owner 和复查计划。
- [ ] 当前 schema 迁移、备份和隔离恢复演练通过。
- [ ] staging 容量、错误率、队列与数据库指标满足批准阈值。
- [ ] HTTPS 域名、证书、代理头、安全响应头和 Cookie 在真实 ingress 验证。
- [ ] 监控平台真实采集多副本指标，告警实际送达具名值班人。
- [ ] 加密异地备份已落地，恢复时间与数据丢失窗口满足 RTO/RPO。
- [ ] staging 镜像回滚及 schema 不兼容恢复路径完成演练。
- [ ] 安全负责人、数据负责人、发布负责人、回滚负责人和值班联系人签署。
- [ ] 正式媒体链、AI 非遗老师和真实商业能力的开放阻断与发布范围一致。

## 立即阻断条件

- 数据恢复不一致或迁移不可逆且无已验证恢复路径。
- 认证/越权回归、共享环境 dev auth、指标无保护或秘密复用。
- 错误率/尾延迟超过门限，Worker 停滞，关键浏览器路径失败。
- 缺少当前备份、不可变镜像、回滚 owner 或告警接收人。
- 把沙盒支付、演示知识或 Mock 模型描述为生产真实能力。

## 当前安全例外

`eslint-config-next` 的间接开发依赖 `braces <=3.0.3` 命中高危深层 pattern 栈耗尽公告，且公告
当前没有修复版本。它不进入 Web 生产镜像的运行依赖，`pnpm audit --prod` 已通过；但 CI 会执行
该工具链，因此风险保持 `OPEN`，需要跟踪上游修复或后续替换受影响的 lint 解析链。

## 决策口径

本机与 CI 通过只能关闭代码和自动化侧条目。需要外部系统、人员或生产数据的条目，在实际验证前
保持 `BLOCKED/UNKNOWN`。只有用户另行明确授权，才可执行外部 staging 或生产变更。
