# S04 全站结构预览（2026-10-21 已批准）

> 批准范围：四大导航、访问型首页、专业工作台归属、三档响应式结构，以及“获批公共目录 + 私人 Workspace”。批准结构不等于后续页面均已实施。

## 设计原则

- 首页是平台访问页与“继续任务”入口，不取代社区、电商或学习首页。
- 顶层始终只有：视频社区、非遗电商、AI 学习、用户中心。
- 浏览、学习、购物是账户默认能力；创作、投稿、经营、知识贡献进入专业工作台。
- reviewer/admin 不出现在公众入口。
- 文化消费页采用舒展布局，专业工作台采用高密度任务布局，移动端优先保留主任务。

## 桌面信息架构

```text
全局顶栏：HAHA | 视频社区 | 非遗电商 | AI学习 | 用户中心 | 搜索 | 头像菜单

首页
├─ 一句话价值 + 主行动（发现内容 / 继续上次任务）
├─ 今日概览（真实任务、消息、成长）
├─ 四大板块状态卡（可用 / 有限 / BLOCKED）
├─ 继续上次进度（观看、学习、订单、专业任务）
└─ 能力边界（AI、交易沙盒、来源可信等级）

视频社区
├─ 发现流 / 搜索 / 专题 / 地区
├─ 内容详情（视频或图文、来源、互动、想学）
└─ 创作者入口：投稿与创作（仅拥有相应工作台时出现）

非遗电商
├─ 商城首页 / 分类 / 搜索
├─ AI 智能导购（主动问候、目录约束推荐、可随时人工浏览）
├─ 商品详情 / 购物车 / 沙盒订单 / 售后
└─ 商家工作台（商品、图片、审核、库存、履约、分析）

AI 学习
├─ 学习首页 / 路径 / 节点
├─ 知识卡 / 测验 / 每日任务 / 成就
└─ AI 非遗老师（真实模型与可信检索不可用时明确 BLOCKED）

用户中心
├─ 今日继续 / 收藏与足迹 / 成长汇总
├─ 消息 / 账户安全 / 隐私
└─ 专业工作台管理（创作者、商家、知识贡献者）
```

## 三档布局

| 视口 | 导航 | 内容 | 关键行为 |
|---|---|---|---|
| ≥ 1200px | 顶栏 + 页面内侧栏 | 12 栏，消费页最大正文宽度受控 | 搜索和主任务始终可发现 |
| 768–1199px | 紧凑顶栏 | 8 栏，侧栏折叠为标签/抽屉 | 不隐藏主要创建、结算或继续按钮 |
| < 768px | 底部五入口（首页 + 四板块） | 单列卡片，筛选用底部抽屉 | 返回遵循浏览器历史；危险操作二次确认 |

## 共用状态和操作习惯

- 每个数据面覆盖 loading、empty、error、permission、success、offline/重试。
- 主按钮使用具体动词，如“提交审核”“加入购物车”，不使用含糊“确定”。
- 取消关闭当前浮层且不保存；返回回到来源页并保留安全的筛选状态。
- 搜索输入在预期位置，Enter 提交，清除按钮可见，零结果提供恢复动作。
- 删除、撤回、退出登录、取消订单等危险操作明确对象、后果与确认按钮。

## 批准结论

1. 上述四导航、首页访问页、专业工作台归属和三档响应式结构作为 S05 之后的 UI 实施基线。
2. “获批公共目录 + 私人 Workspace”作为 D1/D6 实现边界，既有数据默认不公开。
