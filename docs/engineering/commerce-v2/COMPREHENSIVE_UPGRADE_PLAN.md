# 综合升级计划

## Gate M0：合同与安全边界

- 冻结现有 Gate D 回归基线。
- 定义商品目录、SKU、媒体、检索和导购 JSON Schema。
- 明确 AI 允许读取与禁止执行的动作。

退出条件：契约、状态机、权限矩阵和迁移回滚获确认。

## Gate M1：可信商品目录

- 前向迁移扩展商品而不破坏既有订单快照。
- 服务端搜索、分类、排序、分页和可售性过滤。
- 商品详情、媒体、来源与文化关联展示。

退出条件：刷新/重启后商品和 SKU 状态保持，旧 Gate D 路径回归通过。

## Gate M2：买家商城体验

- 新商城首页、当季策展、商品详情、购物车和订单分层。
- 全状态、响应式、键盘与无障碍验收。

退出条件：无 AI 时完整购物任务仍可完成。

## Gate M3：AI 智能导购

- 持久化会话与消息、Catalog Tool、DeepSeek 工作流、Verifier、限流和审计。
- 商品卡推荐、比较、组合和加购草案。
- 固定 Eval：正常、无结果、库存变化、恶意商品文本、越权和模型失败。

退出条件：真实模型测试和故障降级均有证据；推荐零虚构商品 ID。

## Gate M4：商家运营

- 商品/SKU/媒体管理、审核反馈、库存与订单工作台、基础经营信号。
- 商家 AI 助手只做分析/草案，写操作必须预览确认。

## Gate M5：完整验收

- 单元、契约、PostgreSQL、并发、重启恢复、真实浏览器、AI Eval、回归和 CI。
- 保持内部沙盒标签；真实支付等继续 `BLOCKED`。
