# 生产发布门禁

当前结论：`NOT_PRODUCTION_CANDIDATE`。

## 本升级可达到的目标

- 在真实 PostgreSQL、真实 API、真实 DeepSeek 和真实浏览器条件下完成内部商城与导购闭环。
- 保持内部沙盒支付和履约，供开发与比赛演示。

## 发布阻断项

- `BLOCKED`：真实支付、退款、分账、对账与支付合规。
- `BLOCKED`：真实物流、地址保护、运费模板和丢损处理。
- `BLOCKED`：商家主体、经营资质、禁限售、知识产权和消费者保护流程。
- `BLOCKED`：生产级内容/商品审核人力与申诉机制。
- `BLOCKED`：AI 线上监控、成本预算、红队、隐私评估和模型供应商条款复核。
- `BLOCKED`：账户系统邮件验证、找回、MFA、分布式限流等全平台生产门禁。

没有上述证据不得移除“内部沙盒”标识，也不得宣布 Production Ready。
