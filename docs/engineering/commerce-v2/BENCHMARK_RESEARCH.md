# 国内外头部电商平台参考研究

日期：2026-10-20  
口径：这里的“Top”表示规模、行业影响力或某类电商模式的头部/标杆样本，不宣称为同一指标下的严格 1—10 排名。优先采用平台官方、投资者关系或监管披露资料。

## 国内 10 个标杆

| 平台 | 重点参考 | HAHA 取舍 |
|---|---|---|
| 淘宝 | 对话搜索、比较、评价摘要、优惠发现；AI 建立在完整目录上 | 采用“需求追问 + 有证据推荐”，不做自动购买 |
| 天猫 | 品牌旗舰、新品入口、会员与商家经营分析 | 采用当季新品/主题策展和可信商家展示 |
| 京东 | 京言支持主动服务、多轮对话、搜索比较和评价摘要 | 采用主动欢迎但不打扰；首次只给轻量入口 |
| 拼多多 | 高性价比、社交拼购、订单物流透明 | 只参考价值表达与履约可见性，不照搬强刺激玩法 |
| 抖音电商 | 内容、直播、商城、搜索共同承接发现 | 复用 HAHA 视频内容与商品关联，但明确广告/推荐关系 |
| 快手电商 | 直播/短视频之外强化泛货架商品卡和搜索 | 同时保留内容发现和确定性商城搜索 |
| 小红书 | 买手、笔记、直播、商品与信任身份联动 | 适合非遗“人—故事—作品—商品”链路，必须标注经营身份 |
| 微信小店 | 搜索、视频号、社交触点到小店的低摩擦连接 | 参考跨板块入口，不把用户中心变成商城菜单 |
| 唯品会 | 专业买手、精选货盘、限时主题和会员服务 | 采用人工策展优先，不用无限标签制造选择负担 |
| 得物 | 商家资质、鉴别/信任心智和高价值商品风控 | 采用来源与审核分层，不声称平台鉴真能力 |

## 共同模式

1. 对话不是孤岛，而是搜索、详情页、购物车和售后的增强层。
2. 优秀导购先理解“谁、何时、做什么、预算多少”，再谈属性。
3. 推荐必须给可比较的真实商品卡，而不是只输出长文本。
4. 主动服务应克制：欢迎、当季新品和常见任务入口足够，避免遮挡和强弹窗。
5. AI 写操作需要预览、确认和可撤销；支付等高风险动作仍在确定性流程中完成。
6. 对非遗平台而言，人工策展、来源透明和创作者故事比无限个性化更重要。
