# 业务与风险分类

## 用户目标

让普通访客能像进入一家有专业店员的非遗商店一样：先看到可信的当季/主题商品，也可以直接描述送礼对象、预算、使用场景和偏好；导购通过追问收敛需求，给出有依据的商品组合，并把用户安全地送回确定性购物车和订单流程。

## 用户与场景

- 买家：浏览、搜索、咨询、比较、加购、沙盒下单、查看订单与售后。
- 商家：维护商品、SKU、媒体、来源说明、库存和履约，查看基础经营信号。
- 内部审核员：审核商品和来源陈述，不为非遗事实或知识产权背书。
- 平台：确保推荐不越权、不虚构、不展示不可售商品，不让模型直接执行高风险交易。

## 风险等级

| 风险 | 等级 | 控制 |
|---|---|---|
| 模型虚构商品、价格、库存或权威来源 | CRITICAL | 只能引用服务端工具返回的商品 ID 和字段；响应后再校验 |
| 模型未经确认直接下单/支付 | CRITICAL | AI 仅生成购物车草案；结算、支付、地址和售后走确定性 UI 确认 |
| 商家文本提示注入影响导购 | HIGH | 商品文本视为不可信数据；工具输出隔离、长度限制、结构化 Schema |
| 过度个性化或隐私泄漏 | HIGH | V1 不读取私聊、学习答案或敏感资料；偏好显式授权、可清除 |
| 库存/价格在推荐后变化 | HIGH | 推荐显示生成时间；加购和结算重新读取并校验版本 |
| 非遗与授权陈述被误认为认证 | HIGH | 来源、商家声明、平台审核、权威核验分层展示 |
| 大模型费用与延迟失控 | MEDIUM | 轮次/字数/工具次数限制、缓存、超时、失败降级、费用指标 |

## 明确边界

- 当前仍为内部交易沙盒，不接真实支付、退款、结算或物流。
- AI 导购不是“非遗权威专家”，也不替代商品审核、消费者决策或人工客服。
- 用户请求与商品目录无匹配时必须明确无结果，不得编造替代商品。
