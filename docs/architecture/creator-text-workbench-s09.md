# Gate S09 图文 AI 创作切片

状态：实施中（2026-10-22）。本 Gate 不是 Production Ready 声明。

## 决策

- 复用统一账户、工作空间、`creator/contributor` 身份映射和既有 Creator Run，不建立第二套账户或创作栈。
- 模型能力由服务端 `/api/creator/model-capabilities` 声明。真实 DeepSeek 与“本地规则演示（非 AI）”必须在 API、界面和证据中明确区分。
- 单次 Run 最多执行一次模型生成，输出上限 4096 tokens；模型白名单在 HTTP 边界校验，核心服务仍允许测试故障注入。
- `script_versions` 保存不可变原始生成结果；`script_revisions` 保存不可变人工修订与复核事件。客户端不能覆盖原始稿。
- 人工修订采用 `run_id + version` 唯一约束和期望版本校验，重复或并发提交返回冲突。
- 投稿交接只读取服务端 `reviewed` 修订；浏览器本地数据只承担导航定位，不是正文或复核状态事实源。

## 数据迁移边界

迁移 `20261022_0021` 仅新增 `script_revisions`、外键、唯一约束和查询索引。既有项目、Brief、Run 和生成脚本不改写；降级只删除新增表与索引。

## S09 验收路径

1. creator/contributor 进入创作台并看到真实模型可用状态。
2. 选择已配置模型生成，保存模型与检索证据；未配置时不能伪装成真实 AI。
3. 保留原始生成稿，人工修改后保存新版本；刷新/重启后仍可读取。
4. 并发旧版本提交被拒绝，修订历史不可覆盖。
5. 人工确认复核后，服务端才提供图文投稿交接正文。
6. 非写入角色、跨工作空间请求由后端拒绝。
7. PostgreSQL 迁移往返、真实 API、浏览器 E2E 与回归测试通过。

## 后续切片

本文件不包含 S10 图片生成、S11 视频生成或生产发布。S09 尚需完成真实 DeepSeek 受控调用、PostgreSQL/重启验证、浏览器全链路和 CI 后才能收口。
