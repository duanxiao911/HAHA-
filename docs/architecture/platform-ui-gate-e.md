# Gate E：四大板块 UI 集成

顺序状态（2026-10-18）：`IMPLEMENTED_NOT_SEQUENTIALLY_ACCEPTED`。既有 UI 集成与证据保留；Gate C、D 依次收口前，不越序签署 Gate E。

## 目标与边界

Gate E 统一视频社区、非遗电商、AI 学习与用户中心的全局入口、账户身份入口和响应式导航。它复用 A–D 已有的统一账户、权限与服务端事实源，不新增数据库表、迁移、账户体系或平行前端技术栈。

本 Gate 不把生产级媒体处理、真实支付或正式文化事实认证解释为已完成。AI 非遗老师由运行时能力探测决定：真实模型与内部复核知识库可用时进入受控提问，不可用时显示 `BLOCKED`；电商继续显示 `INTERNAL SANDBOX`。

## 信息架构决策

| 路由 | 定位 | 主要内容 |
|---|---|---|
| `/` | 中立的平台首页 | 四大板块入口、跨模块今日摘要、继续进度与能力边界 |
| `/community` | 视频社区 | 内容发现、观看互动、想学与创作者工具 |
| `/commerce` | 非遗电商 | 商品、购物车、订单、经营和审核沙盒 |
| `/learning` | AI 学习 | 学习路径、知识卡、测验、每日任务、连续学习与成就 |
| `/identity` | 用户中心 | 身份、文化资产、通知任务、成长汇总与账户设置 |
| `/creator` | 社区内的创作者工作台 | 图文脚本创作与投稿衔接，不占用第五个全局模块入口 |

`/` 与 `/identity` 明确分离：平台首页负责分流和跨模块恢复；用户中心负责“我的”账户管理。用户中心内部不再重复展示“用户中心”入口卡。

## 导航与交互契约

- 桌面顶部固定四个模块入口：视频社区、非遗电商、AI 学习、用户中心；点击品牌标识返回平台首页。
- 根首页不错误高亮任何模块；模块页及其子路由高亮所属模块。
- 移动端固定五个入口：首页、社区、学习、电商、我的。
- 全局账户入口显示服务端读取的当前业务身份；菜单只允许快捷切换已授权身份，切换仍由后端验证。
- 用户中心是身份与权限的主入口；首页只展示当前身份感知与开通/申请引导，不提供身份切换器。
- “切换已开通身份”与“开通/申请身份”使用不同文案和操作路径；持久开通前需二次确认。
- 创作、投稿、审核与经营操作放在所属模块或身份工作台，不挤占全局一级导航。
- 全局搜索使用常规搜索框和提交行为；菜单支持 `Escape` 与点击外部关闭。
- 危险业务操作继续复用既有确认对话框，本 Gate 不改变其领域状态机。

## 状态与响应式

平台首页的个人摘要覆盖 loading、empty、error 和 authenticated/anonymous 状态；各模块继续保留自己的 permission、success 与业务错误状态。目标断点为 390、768、1024、1440，不允许横向溢出；移动端底部导航保留安全区。

## 兼容、迁移与回滚

- API、数据库和权限契约无变化，无 Alembic 迁移。
- 既有 `/community`、`/commerce`、`/learning`、`/identity`、`/creator` 路由保持可用。
- 回滚只需恢复 Gate E 前端文件；A–D 数据不受影响。
- 本地 GitHub Pages 演示和真实 API 模式仍必须分别显示其数据边界，不以静态页面代替真实环境验收。

## 验收标准

1. 根首页与用户中心不重复，四模块入口位置稳定且含义明确。
2. 社区使用统一 Header，同时保留频道二级导航。
3. 当前身份可见、可发现；非授权身份不能通过前端切换获得权限。
4. AI 学习与电商边界标签始终诚实展示。
5. 390、768、1440 浏览器视口无横向溢出，移动端恰好五个主入口。
6. lint、前端契约、Next.js 生产构建、全量 pytest 和真实 Chrome E2E 通过。
