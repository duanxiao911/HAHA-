# G4 未解决问题与风险

## 状态定义

- `OPEN`：已确认但未纳入本轮。
- `UNKNOWN`：缺少外部或远端执行证据。
- `BLOCKED`：依赖尚不存在的真实领域/API。

## 风险清单

| 优先级 | 状态 | 问题 | 影响与下一步 |
|---|---|---|---|
| P0 | `UNKNOWN` | GitHub Actions 远端结果 | 推送后必须检查新提交的 backend/frontend/container/browser jobs；未绿灯前不宣称远端 CI 通过 |
| P0 | `BLOCKED` | AI 非遗学习没有真实模型、知识检索和 Eval | 保持能力 `blocked`；下一垂直切片需定义会话、来源引用、评测、成本与失败恢复 |
| P0 | `BLOCKED` | 电商没有商品、订单、支付、履约和售后领域 | 不展示虚构订单；先做交易沙盒和状态机，再开放买家/卖家经营能力 |
| P0 | `BLOCKED` | 四模块统一审核后台尚未建立 | 需要内容/知识/商品/身份审核对象、队列、证据、决定、申诉和审计事件 |
| P1 | `OPEN` | 视频社区仍含本地数据适配器 | 真实内容、互动、搜索和发布 API 接入前，首页/社区数据不能视为生产真实数据 |
| P1 | `OPEN` | 外部预发布 HTTPS 与云主机验收未执行 | 需要域名/TLS、最小安全组、备份恢复、迁移、监控和真实公网 smoke 证据 |
| P1 | `OPEN` | Docker Python 依赖层缓存效率低 | `src` 在依赖安装前复制，源码变化会重新安装依赖；后续拆依赖层并验证锁定版本 |
| P2 | `OPEN` | Starlette TestClient 弃用警告 | 当前不影响功能；后续按兼容矩阵迁移到推荐 HTTP 测试客户端 |
| P2 | `OPEN` | 工作台投影使用同步聚合调用 | 当前内部演示规模可接受；接入大数据量后需增加分页、查询预算和性能基线 |

## 发布判断

G4 功能切片可以进入后续开发，不能因此宣布 Production Candidate。Production Readiness Gate 至少仍需：

1. 推送后的 GitHub CI 全绿记录。
2. 外部 HTTPS 预发布环境与真实域名验证。
3. 数据库备份/恢复演练和迁移回滚证据。
4. 依赖/镜像安全扫描与运维责任人确认。
5. 视频、AI、电商和审核真实 API 各自的功能与风险验收。
